# Professional portraits

`valentina-portrait.jpg` is the untouched source photo supplied by Valentina in the uploaded ZIP. The hero and biography use `valentina-portrait-no-logos.png`, a transparent background-removal edit. The branded event backdrop, lanyard and badge are removed as requested by Valentina. Responsive framing uses CSS, and Next Image optimizes delivery. The SVGs are retained decorative fallback monograms.

Add your real photographs here as `valentina-hero.jpg` and `valentina-about.jpg`. Then set `site.images.hero` and `site.images.about` to those paths in `config/site.ts`, and set `hasPortraits: true`. Do not remove the existing placeholders until the new files are available. Images render through Next Image with defined dimensions.
